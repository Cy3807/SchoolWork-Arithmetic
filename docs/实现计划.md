# 小学四则运算程序实现计划

补做日期：2026 年 10 月 9 日。代码和技术文档由 Codex 协助完成，学生需实际运行、理解并审核提交内容。

## 需求与验收

1. `-n` 控制数量，未指定时默认 10；`-r` 必填且至少为 1。
2. 操作数数值和分母均小于 `r`；范围只约束题目操作数，不限制答案与中间结果。
3. 每道题使用 1 至 3 个运算符；每个减法节点非负，每个除法节点结果严格在 0 和 1 之间。
4. 用有理数精确运算，输出自然数、最简分数、带分数。
5. 表达式树保留运算结构，只对加法和乘法节点交换两侧，规范键放入集合判重。
6. 在当前工作目录输出编号对应的 Exercises.txt 和 Answers.txt；支持 10000 道。
7. `-e/-a` 读取题目和学生作答，重新求值并输出 Grade.txt。
8. 至少 10 个有明确预期的测试，另做 10000 道题逐节点检查和文本重新解析验证。
9. 同一随机种子和候选序列下，比较列表查重与集合查重；用 cProfile 定位热点并生成 PNG 图。

## 实现顺序

分数与表达式 → 参数和生成 → 批改 → 测试 → 基准与图 → 博客、运行及提交说明。

核心程序只用 Python 标准库，兼容 Python 3.9 及以上。绘图脚本单独使用 matplotlib。
