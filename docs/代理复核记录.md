## 去重与括号的额外独立检查

新增的 `reports/agent-review/review.py` 将规范题面转换为 Python AST，自己走访白名单节点并用 `Fraction` 求值。其独立求值部分没有调用项目的 `parse_expression`，也没有导入已有测试的双栈求值器。

对生成的 10 题、README 随机 10 题和固定种子 10000 题，分别独立核对了编号、行数、每题 1 至 3 个运算符、操作数及分母范围、所有减法子式非负、所有除法子式严格在 0 与 1 之间、题面与答案精确相等，全部通过。

去重检查穷举每棵小树在加法、乘法节点交换左右子树后的所有变体，以完整树形表示的最小值作为独立判据，没有使用生产代码的 `key()` 判断一万题是否重复。固定种子的一万题无重复。另单独将下列规则与生产 `key()` 对照：

| 题面组合 | 独立判定及生产结果 |
| --- | --- |
| `23+45` 与 `45+23` | 重复 |
| `6×8` 与 `8×6` | 重复 |
| `3+(2+1)` 与 `1+2+3` | 重复 |
| `1+2+3` 与 `3+2+1` | 不重复 |
| `1+4` 与 `2+3` | 不重复，结果相同不代表树相同 |
| `3-2` 与 `2-3` | 不重复 |
| `1 ÷ 2` 与 `2 ÷ 1` | 不重复 |

括号检查覆盖了 4 种父运算符、4 种子运算符、左右两种位置，共 32 棵树。将渲染结果独立解析后，比对精确值和完整左右树形，全部一致；生产解析器回读也一致。例如同优先级右子树 `11 + (9 + 2)`、`11 − (9 − 2)`、`11 × (9 ÷ 2)`、`11 ÷ (9 ÷ 2)` 均保留括号。这里部分人工构造的渲染测试树含负值或非真分数除法，仅用于覆盖通用渲染逻辑，不作为生成器合法题目的样本。
